# -Develop-GenAI-Apps-with-Gemini-and-Streamlit


Project build and deploy AI Chef, a generative AI proof-of-concept application for Cymbal Health on google cloud , a regional health network aiming to improve customer nutrition and wellness. The app uses Google's Gemini model to generate personalized recipe recommendations based on a customer's cuisine preference, dietary restrictions, food allergies, wine preference, and ingredients already on hand. The work spanned the full development lifecycle: first validating connectivity to the Gemini API using cURL in a Jupyter notebook, then building the application's front end and prompt logic in Python using the Streamlit framework, testing the app locally in Cloud Shell, containerizing it with Docker and pushing the image to Artifact Registry, and finally deploying the finished service to Cloud Run so it could run as a publicly accessible web application. Along the way, the project involved real troubleshooting  fixing a broken multi-line string in the Gemini prompt, correcting an invalid Gemini client argument, and replacing a placeholder model ID  mirroring the kind of debugging required when turning a generative AI prototype into a deployed, production-ready service
